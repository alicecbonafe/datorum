Datorum documentation
=====================

A settings-based framework for creating AI agents and pipelines, focusing on the high
specialization of language models using context engineering.

By bringing context to the forefront, Datorum enables greater specialization for AI agents and reduces prompt noise. Abstracting away the logic of tools, agents, and pipelines frees the agent creator to focus on document curation and contextual accuracy, thereby boosting the capabilities of smaller models and improving the efficiency of larger ones.
